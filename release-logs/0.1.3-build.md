## Build dan verifikasi

- Versi aplikasi di `Cargo.toml`, `src-tauri/Cargo.toml`, dan `src-tauri/tauri.conf.json` dinaikkan ke `0.1.3`. Versi Android dinaikkan ke `versionCode` `1003`.
- Portable dibuat dengan `cargo tauri build --no-bundle --ci --target x86_64-pc-windows-msvc`.
- Installer NSIS dibuat dengan `cargo tauri build --ci --bundles nsis --target x86_64-pc-windows-msvc`.
- APK dibuat dengan `cargo tauri android build --apk --target aarch64 --split-per-abi`, lalu Gradle `:app:assembleArm64Release` setelah library Rust disalin sebagai file biasa ke `jniLibs/arm64-v8a` karena Windows pada mesin build melarang symbolic link.
- APK melaporkan `versionName=0.1.3`, `versionCode=1003`, ABI `arm64-v8a`, dan lolos `apksigner verify` dengan satu signer, skema APK Signature v2. Sertifikat penandatangan sama dengan APK 0.1.2.
- MSI standar tertahan saat pemeriksaan ICE karena layanan Windows Installer tidak dapat diakses. MSI tetap dibuat menggunakan WiX Light dengan opsi `-sval` yang melewati validasi MSI; WiX Dark berhasil membaca dan mendekompilasi paket serta mengonfirmasi versi produk `0.1.3`. Karena itu, pemeriksaan ICE MSI belum terverifikasi.
- Versi portable dan installer NSIS menunjukkan `ProductVersion=0.1.3`.

## Catatan

Build APK dan aplikasi Windows selesai. Tes aplikasi tidak dijalankan dalam proses pembuatan artefak rilis ini.
